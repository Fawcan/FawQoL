Collection of Quality of Life additions to World of Warcraft Forever.
Trying to keep it as lightweight as possible to have as low impact on the game.


Current Modules:

Extended Vendor UI - Increases the Columns and Rows for vendor window.
Does not support textures from EllesmereUI etc, the added slots will be Blizzard style, to keep it as lightweight as possible

Gather Minimap Range Circle - An addition GatherMate2 had, but I can't seem to get it to work, shows a ring around the player on the minimap of how far you can see Gathering nodes
